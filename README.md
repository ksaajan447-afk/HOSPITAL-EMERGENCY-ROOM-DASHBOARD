# Hospital Emergency Room Dashboard

## 📊 Project Overview
This Excel project analyzes hospital emergency room data using pivot tables and dashboards.

## ✨ Features
- Patient admission analysis
- Daily/Monthly case trends
- Charts for quick visualization
- Conditional formatting for critical cases

## 🛠️ Tools Used
- Microsoft Excel (Pivot Tables, Charts, Dashboard)

## 🚀 How to Use
1. Download the Excel file from this repository.
2. Open in MS Excel.
3. Explore the Dashboard sheet for insights.
